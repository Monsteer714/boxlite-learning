# pip install vs make dev:python

The quickstart promises a 5-minute `pip install boxlite` setup, yet the examples require `git clone` + `make dev:python`. This implies the published PyPI package may lag the repo examples, or the examples require dev-mode builds. Worth verifying whether `pip install boxlite` supports all nine examples out of the box.
