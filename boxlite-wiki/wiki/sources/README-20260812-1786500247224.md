## Key Concepts

1. **Protected Stateful Runner** — the Runner holds `/var/lib/boxlite` and live microVMs on its root disk; `protect: true` + `ignoreChanges: ['ami', 'userDataBase64']`; the CI gate rejects any create/replace/delete/protected-property change. Most important operational invariant in the document.
2. **Symmetric artifact deployment** — both deployable components (API, Runner) are selected by one source selector (`build` = immutable `v<version>-<sha>`; `release` = stable `VERSION`); no deploy compiles the API except a fallback path. Both modes hand SST an image reference.
