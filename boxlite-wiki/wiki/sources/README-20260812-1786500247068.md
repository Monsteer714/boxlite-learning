## Key Entities

### Central (new to wiki unless noted)

| Entity | Type | Role in Source | In Wiki? |
|---|---|---|---|
| **JsBoxlite / Boxlite** | Runtime class (Node SDK) | Main entry point; constructor + `withDefaultConfig()`/`initDefault()`; `create()`, `listInfo()`, `getInfo()`, `get()`, `metrics()`, `remove()`, `close()` | New — but conceptually the Node binding of [[entities/boxlite-runtime\|BoxLite Runtime]]; should be linked, not a duplicate |
| **JsBox** | Low-level box handle | Per-box control: `id`, `name`, `network`, `info()`, `exec()`, `stop()`, `metrics()` | New — analogous to [[entities/litebox\|LiteBox]] (per-Box runtime handle); SDK-level counterpart |
| **SimpleBox** | High-level wrapper class | Context-managed execution with auto-cleanup (`autoRemove` default **true**), `exec()` variadic + array forms, `[Symbol.asyncDispose]` | ⚠️ Exists, but **API surface differs** from wiki (see Contradictions) |
| **CodeBox** | Specialized box (Python) | `run()`, `runScript()`, `installPackage()`; default image `python:slim` | New |
| **BrowserBox** | Specialized box (browser automation) | CDP endpoint; chromium/firefox/webkit; ports 9222/9223/9224; Playwright/browserless images | New |
| **ComputerBox** | Specialized box (desktop GUI) | Mouse/keyboard/display automation; xdotool key syntax; GUI via ports 3000/3001; screenshot base64 PNG | New |
| **InteractiveBox** | Specialized box (PTY) | Interactive shell sessions; `tty: undefined` = auto-detect from stdin | New — extends [[concepts/pty-support\|PTY Support]] |

### Peripheral utilities

| Entity | Type | Role | In Wiki? |
|---|---|---|---|
| **BoxliteError / ExecError / TimeoutError / ParseError** | Error class hierarchy | `BoxliteError` base; `ExecError` carries `command`, `exitCode`, `stderr`; `TimeoutError`; `ParseError` | New |
| **puppeteer-core** | External library | Used in BrowserBox example to connect to the CDP endpoint | New (external dependency, minor) |

### Key TypeScript types (new, represent the SDK contract)

- `JsOptions` (runtime config: `homeDir`, `imageRegistries`)
- `JsBoxOptions` (create config: image/rootfsPath, cpus, memoryMib, diskSizeGb, workingDir, env, volumes, **network**, ports, secrets, advanced, autoRemove, detach)
- `NetworkSpec` (`mode: "enabled"|"disabled"`, `allowNet?: string[]`)
- `JsPortSpec` (request) vs `JsPublishedPort` (resolved) — distinct types
- `Secret` (with `placeholder` default `<BOXLITE_SECRET:${name}>`)
- `JsBoxInfo` / `JsNetworkInfo` (with `publishedPorts: JsPublishedPort[] | null`)
- `JsExecution`, `JsExecStdin`, `JsExecStdout`/`JsExecStderr`, `JsExecResult`
- `ExecResult` (wrapper: `exitCode`, `stdout`, `stderr`)
- `JsRuntimeMetrics`, `JsBoxMetrics` (counters, resource fields, create-pipel
