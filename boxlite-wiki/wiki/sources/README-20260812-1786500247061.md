## Key Concepts

| Concept | Definition & importance | In wiki? |
|---|---|---|
| **Credential precedence** | `BOXLITE_API_KEY` env > `~/.boxlite/credentials.toml` (0600) > unauthenticated local runtime. Core of the new cloud mode. | No |
| **`--url` short-circuit** | `--url` bypasses the local hypervisor entirely; `--home`/`--registry`/`--config` ignored. Defines local-vs-remote architecture split. | Partially (rest-api-websocket-exec) |
| **Job vs service boxes** | `create` **with** a command stores it as init → box is a *job*; `exec`/`cp` refuse to start it implicitly. `create` without a command → boots image default; `exec` may start on demand. This is the CLI face of config-gated restart refusal. | Partially — [[concepts/config-gated-restart-refusal\|Config-Gated Restart Refusal]] |
| **Run-command semantics** | `run IMAGE [COMMAND...]`: COMMAND replaces CMD, ENTRYPOINT prepended, result is PID 1; box lifetime = command lifetime; exit code propagated. | Yes — [[concepts/run-command-semantics\|Run-Command Semantics]] |
| **Exit-code conventions** | `0` success; `1` runtime error; `2` clap usage; `N` (1–127) box command status; `128+N` signal death. Multi-target commands aggregate errors. | Partially — [[concepts/exit-record\|Exit Record]] |
| **Supply-chain verification** | Layered anchors: `.sha256` sidecars, combined `SHA256SUMS`, sigs
