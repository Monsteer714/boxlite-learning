## Key Concepts

- **Deny-by-default posture** — `(deny default)` with explicit allowlists. Core design principle of the shipped profile; explains why *any* missing allow clause produces a denial.
- **SBPL rule patterns** — `literal` (single path), `subpath` (directory tree), `regex`, `sysctl-name`/`sysctl-name-prefix`, `global-name` (mach services). Prefer minimal rules (`literal` over `subpath`).
- **Compile-time policy embedding** — `.sbpl` files embedded via `include_str!`; changes require forcing recompilation (`cargo clean -p boxlite` or `make dev:python`). A common source of "changes not taking effect."
- **macOS unified logging** — `log stream`/`log show` with predicates (`subsystem == "com.apple.sandbox"`, `eventMessage CONTAINS "deny"`) as the denial interface; kernel messages (`senderImagePath == "/kernel"`) are most reliable.
- **Denial taxonomy** — operation/target pairs: `file-read-data`, `file-read-metadata`, `file-write-create`, `sysctl-read`, `mach-lookup`, `network-outbound`, `iokit-open`. Format: `Sandbox: boxlite-shim(PID) deny(1) OPERATION TARGET`.
- **Path canonicalization** — macOS symlink aliases (`/tmp` → `/private/tmp`, `/var` → `/private/var`); policies must use canonical paths.
- **Dynamic policy assembly** — runtime policy = static SBPL fragments + dynamic path grants (binary, volumes, box_dir) joined in Rust.
