## Key Concepts

- **Library-first, daemonless use** — `BoxliteRuntime::default_runtime()` is called directly in application code, with no daemon or root process. This is a concrete illustration of [[concepts/daemonless-embedding|Daemonless Embedding]].
- **Create box from OCI image** — `BoxOptions { rootfs: RootfsSpec::Image("alpine:latest"), ..Default::default() }` shows that a box is created directly from an OCI image reference, rather than from a pre-provisioned VM image. Reinforces [[concepts/oci-image|OCI Image]] usage.
- **Async execution and streaming stdout** — the API is `async` (tokio-based), and stdout is consumed as a `Stream` via `futures::StreamExt`. This is the first source in the wiki to clearly document the client-side streaming pattern for exec output.
