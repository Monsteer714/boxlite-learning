# Source Analysis: Python SDK API Reference

**File:** `README-20260812-1786500247030.md` — Complete API reference for the BoxLite Python SDK (Python 3.10+, macOS Apple Silicon, Linux x86_64/ARM64).

This is a *prescriptive reference document* rather than a report or post-mortem. Its value to the wiki is twofold: it canonically defines the Python SDK surface, and it reveals a richer product story (specialized box types, sync API, tunnels) not yet captured in the index.

## Key Entities

| Entity | Type | Role | Exists in wiki? |
|---|---|---|---|
| **BoxLite Python SDK** | Product/library | Subject of the entire document | ⚠️ No dedicated page ([[entities/boxlite-runtime|BoxLite Runtime]] is adjacent but not SDK-language-specific) |
| **`Boxlite`** (runtime class) | API class | Central — `default()`, `create()`, `get()`, `get_info()`, `list_info()`, `metrics()` | ⚠️ Covered by [[entities/boxlite-runtime|BoxLite Runtime]] entity but method surface is new |
| **`Box`** | API class | Central — handle with `exec/stop/remove/info/metrics` + `network` property | ✅ [[entities/box|Box]] exists; surface details are new |
| **`SimpleBox`** | API class | Central — context manager, `start()/exec()/info()/shutdown()` | ✅ [[entities/simplebox|SimpleBox]] exists, but the Python surface here (start/exec/info/shutdown) differs from the index entry (`attach()`, `wait()`, `Boxlite.run()`) — likely another SDK language's surface |
| **`CodeBox`** | API class | Central — specialized Python-code execution with pip install | ❌ New |
| **`BrowserBox`** | API class | Central — CDP browser automation (chromium:9222, firefox:9223, webkit:9224) | ❌ New |
| **`ComputerBox`** | API class | Central — full desktop GUI + mouse/keyboard/display automation (xdotool syntax) | ❌ New |
| **`InteractiveBox`** | API class | Central — PTY shell sessions, TTY auto-detect via `sys.stdin.isatty()` | ❌ New |
| **`Options` / `ImageRegistry`** | Config types | Central — home dir; registry transport/TLS/auth (basic, bearer, `skip_verify`, `search`) | ❌ New |
| **`BoxOptions` / `AdvancedBoxOptions` / `ContainerCapabilities`** | Config types | Central — capabilities `add`/`drop` intentionally nested under `advanced` | ⚠️ Partially related to [[concepts/oci-image|OCI Image]] / run semantics; the config object itself is new |
| **`NetworkSpec`** | Config type | Central — `mode="enabled"/"disabled"`, `allow_net` list; disabled removes guest NIC entirely | ⚠️ Related to [[concepts/allow-net|allow_net]] |
| **`Secret`** | Config type | Central — placeholder defaults to `<BOXLITE_SECRET:name>` | ⚠️ Related to [[concepts/secret-injection|Secret Injection]]; concrete format is new |
| **`Execution` / `ExecStdout` / `ExecStderr` / `ExecStdin` / `ExecResult`** | API classes | Central — streaming exec; single-iteration streams | ❌ New as entities |
| **Sync API classes** (`SyncBoxlite`, `SyncBox`, `SyncSimpleBox`, `SyncCodeBox`, …) | API classes | Central — greenlet-based sync wrappers for Jupyter/REP
