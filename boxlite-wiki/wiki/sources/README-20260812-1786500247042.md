# Source Analysis: BoxLite Rust API Reference

**Document type:** SDK API reference (primary source for the Rust crate's public surface)
**Relationship to wiki:** This is the *canonical API contract* for the Rust SDK — it substantiates and extends many existing wiki pages, and introduces several entirely new entities/concepts not yet captured.

---

## Key Entities

| Entity | Type | Role | Already in wiki? |
|---|---|---|---|
| `BoxliteRuntime` | Rust struct (runtime entry point) | **Central** — main entry point; factory for boxes; global singleton pattern | Partially — [[entities/boxlite-runtime\|BoxLite Runtime]] exists at the concept level, but the concrete Rust API (create/get/list/remove/metrics, `default_runtime`) is new |
| `LiteBox` | Rust struct (box handle) | **Central** — full method surface now documented (`run`, `start`, `stop`, `info`, `metrics`, `network`) | Yes — [[entities/litebox\|LiteBox]] exists; this doc significantly extends it |
| `BoxOptions` / `AdvancedBoxOptions` | Config structs | **Central** — full box configuration surface | Partially — relates to [[entities/simplebox\|SimpleBox]]'s `BoxOptions`, but Rust `BoxOptions` with `rootfs`, `volumes`, `network`, `secrets`, `ports`, `detach`, `auto_remove`, `advanced` is new detail |
| `BoxCommand` | Command builder | **Central** — `new/arg/args/env/timeout/working_dir/user/tty` | **New** — not in index |
| `Execution` + `ExecStdin`/`ExecStdout`/`ExecStderr`/`ExecResult` | Execution handle + streams + result | **Central** — run model; `wait()`/`kill()`/`signal()`/`resize_tty()`; `futures::Stream<Item = String>` | **New** — not in index |
| `BoxStatus` / `BoxState` / `BoxInfo` | Enums/structs | **Central** — lifecycle state machine (Configured/Running/Stopping/Stopped/Unknown) with `can_*` predicates | **New** — not in index (wiki has no lifecycle state machine page) |
| `SecurityOptions` / `SecurityOptionsBuilder` / `ResourceLimits` | Security types | **Central** — two-state security model; builder presets; rlimits | **New** — extends [[concepts/sandboxing-layers\|Sandboxing Layers]] with the concrete API |
| `NetworkHandle` / `BoxTunnel` / `BoxConnection` / `BoxReader` / `BoxWriter` | Tunnel types | Central-ish — one-shot connection model distinct from port publishing | **New** — not in index |
| `RuntimeMetrics` / `BoxMetrics` | Metrics structs | Central-ish — runtime-wide counters; per-box metrics incl. 6-stage boot timing | **New** — not in index |
| `ImageRegistry` | Registry config | Central-ish — search order, TLS/auth options | **New** — not in index (ties to [[concepts/oci-image-caching\|OCI Image Caching]]) |
| `BoxliteError` / `BoxliteResult` | Error enum + alias | Central (cross-cutting) — 19-variant taxonomy mapping to subsystems | **New** — not in index |
| `BoxID` / `BoxIDMint` / `ContainerID` / `LockId` | ID types | Peripheral — Base62 12-char BoxID (~71-bit entropy); 64-char hex ContainerID; legacy ULID acceptance | **New** — not in index |
