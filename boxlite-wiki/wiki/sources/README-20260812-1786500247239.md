## Key Concepts

1. **Full production path** — `Python SDK (rest) → HTTP → NestJS API → HTTP → boxlite-runner → libkrun VM`. The gap being closed: existing `make test:integration:*` tests use `Boxlite.default()` (PyO3/FFI) and bypass both API and runner, so chain-only bugs reach production.
2. **Test path verification (meta-test)** — a dedicated test asserts both :3000 and :8080 received the expected HTTP requests via log/journalctl tailing. If it passes, every other case uses the same fixtures and the same path. Guards against silent fixture drift.
